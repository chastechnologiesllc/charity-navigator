## Excluded candidates

- **Syrian refugee family portrait:** [Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:A_syrian_refugee_family_lving_in_Jordan.jpg). It is CC BY-SA 4.0 and permits commercial reuse with attribution and share-alike, but its caption identifies Shahed as a 16-year-old orphan caring for siblings and the file page does not document a model release or consent record. It is not used in the fundraising page.
- **U.S. Marine Corps shelter imagery:** [DVIDS image page](https://www.dvidshub.net/image/1159384/marines-volunteer-local-homeless-shelter) marks the photo public domain, but the [DVIDS public-use notice](https://www.dvidshub.net/about/copyright) says fundraising/solicitation is commercial use, requires a non-DoD endorsement disclaimer to the extent practicable, and requests obscuring distinctive military marks. It also says publication does not waive subjects’ privacy/publicity rights. Not used.
- **USDA food-bank images:** the [San Antonio distribution file](https://commons.wikimedia.org/wiki/File:20200417-FNS-LSC-0410_(49785830128).jpg) is public domain but the inspected frame is a close-up of a box label. The [Capital Area Food Bank file](https://commons.wikimedia.org/wiki/File:Capital_Area_Food_Bank_(20211202-FNS-LSC-0484).jpg) is public domain and shows a masked volunteer packing boxes, but it was not selected for this page.
- **U.S. Navy Yokohama meal-service photo:** [Commons file page](https://commons.wikimedia.org/wiki/File:US_Navy_071119-N-5253W-004_Members_of_the_Commander_Fleet_Activities_Yokosuka_Multicultural_Committee_serve_a_hot_meal_at_the_Sanagi-tachi_Homeless_Shelter_in_Yokohama.jpg). Public domain as a U.S. Navy official-duty work, but it is an overseas scene and is not used here.

The existing charity-card images were already part of the application and are reused unchanged. Avoid copy that implies any photograph is of a featured charity, its services, or its beneficiaries unless a source record confirms that relationship.
